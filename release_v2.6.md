## 🎨 User Interface & Experience Update (v2.6)

**What's New in v2.6**

* 🌌 **Interface Redesign**
  The extension popup has been redesigned with a darker theme and updated typography (Inter font) for improved readability and navigation.

* 🌦️ **Weather Integration**
  Added a weather widget to the main dashboard. This fetches local weather data and can be disabled at any time in the settings menu.

* 🔗 **Custom Quick Links**
  Introduced a new link manager. You can now add, edit, or remove your own custom quick links directly from the extension. Site icons (favicons) are fetched automatically.

* ⚙️ **Granular Settings**
  The settings tab now includes individual toggles for the background network monitor and the weather widget, allowing you to turn off background tasks you don't need.

* 🚨 **Factory Reset**
  Added a 'Wipe Vault' button in the settings. This provides a direct way to instantly delete all locally stored passwords and custom configurations from your device.

* ⚡ **Codebase & Performance**
  Separated the UI styles into a dedicated `popup.css` file to improve maintainability. We also refined the toast notification system for clearer user feedback and optimized background state management.
